# 03 UI 规格（对齐已确认的 6 张效果图）

> **效果图的权威范围 = 版式**。6 张效果图对齐的是版式、卡片结构、信息层级、配色与文案位置；
> 其**工程数值与器件数据不具权威性**（三处已知不自洽见 `docs/05` §16.2）。

## 全局 Shell
- 顶栏（深色 #0d1117 系）：Logo「Board Debug Copilot / 准 LabSight」｜项目切换下拉（Sensor Board Debug Demo）｜设备状态下拉（● ADALM2000 已连接，绿点；未连接灰点+「启动 Bridge」引导）｜全局 AI 搜索框「问 AI 助手（按 Ctrl+K）」｜文档图标｜通知铃铛(角标)｜用户头像 ZH
- 左侧导航（浅色）：项目总览 / 设计审查 / 调试工作台 / PCB照片 / 调试计划 / 测试报告 / 元器件库，底部 设置
- 内容区浅灰底 #f5f7fa，卡片白底圆角 12px 细边框
- 主色蓝 #2563eb，风险色：高=红、中=橙、低=蓝/灰、正常=绿；标签为圆角小 pill
- 全站中文；Ctrl+K 打开全局 AI 命令面板（MVP：跳到当前页 Copilot 输入框）

- 中间：实时波形(时域)卡 — CH1:TP1(IN) 绿 / CH2:TP2(OUT) 橙 tag，右上 V/div、时基、采样率、●停止、全屏；黑底网格双通道波形（Canvas，ResizeObserver+DPR）；频域(FFT)卡 — CH1/CH2 tag、窗函数 Hann、线数1024、黑底 dBV 频谱；测量结果网格：Vpp/Vrms/Freq/Gain(CH2/CH1)+dB/Phase/Offset/THD+N 每格 CH1 CH2 两行 + 测量说明；仪器控制条：时基/触发(源沿电平)/采样率/垂直(每通道V/div+耦合)/运行控制(Auto/运行/停止)

## 页面 5：调试计划 `/projects/[id]/plan`
- 标题「调试计划 [AI生成]」+ 右上「重新生成计划 / 导出计划▾」
- 问题描述横幅：0号圆标 + 问题（输出无响应 Vout 一直为 0V）+ 目标
- 左 55% 调试流程树（共22步，全部展开/折叠）：5 个分组（电源检查5/输入激励检查3/运放工作点检查4/焊接与装配检查3/协议与数字信号4）+ 添加自定义步骤；每行 = 编号标题 + 建议工具列 + 预计耗时列；分组行前有完成状态圆标；选中行高亮
- 右 45% 步骤详情（3.1 检查反相端电压 V- ｜AI推荐 pill｜步骤ID）：操作目标 / 连接与设置(ADALM2000)(模式DMM/通道/接线方式/量程/触发) / 目标网点与器件(网点 U1_IN- Net:N0012、器件 U1 引脚2) + 右侧预期参考值大数字卡(0.8mV 直流电压)+历史参考照片(带 U1-/GND 标注) / 预期结果 / 异常情况与下一步(两条 →) ；底部按钮：开始测量(主)/标记完成/创建调试记录
- 底部两卡：最近完成的步骤(绿勾+实测值+正常pill+相对时间)、已采集证据(tab: 全部/电压12/波形5/截图3/日志2，证据卡带缩略图)
